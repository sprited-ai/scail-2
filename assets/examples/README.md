# Public example inputs

These AI-generated assets are the inputs used by the public Replicate examples.

- `clay-gardener.png`: clay-style gardener reference.
- `greenhouse-robot.png`: robot reference.
- `wave-driving.mp4`: waving motion generated with AniSora; this is synthetic footage.

The examples transfer the same driving motion to each reference. Hosting the inputs here lets visitors view and reuse them without an authenticated Replicate file URL.
